# Homebrew Tap

Homebrew formulae maintained by [Mark Jaquith](https://github.com/markjaquith).

## cowtree

[`cowtree`](https://github.com/markjaquith/cowtree) creates and compacts macOS
Git worktrees using APFS copy-on-write clones.

Until the first tagged release, install the latest development version with:

```sh
brew install markjaquith/tap/cowtree --HEAD
```
